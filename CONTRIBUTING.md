# Contribuindo para WhatsApp API

Obrigado por considerar contribuir! Cada contribuicao e valorizada.

## Como contribuir

### Reportar Bugs

1. Verifique se o bug ja foi reportado em [Issues](https://github.com/matheus24scc/whatsapp-api/issues)
2. Se nao, abra um novo issue com:
   - Titulo claro e descritivo
   - Steps para reproduzir
   - Comportamento esperado vs atual
   - Versao do Node.js e SO

### Sugerir Features

1. Abra um issue com a tag `enhancement`
2. Descreva:
   - Problema que a feature resolve
   - Como voce imagina a solucao
   - Exemplos de uso

### Enviar Pull Request

1. Fork o repositorio
2. Crie uma branch para sua feature (`git checkout -b feature/nova-feature`)
3. Commit suas mudancas (`git commit -m 'feat: add nova feature'`)
4. Push para a branch (`git push origin feature/nova-feature`)
5. Abra um Pull Request

### Regras de Commit

Seguimos [Conventional Commits](https://www.conventionalcommits.org/):

```
feat:     nova feature
fix:      correcao de bug
docs:     documentacao
style:    formatacao
refactor: refatoracao
test:     testes
chore:    manutencao
```

Exemplo:
```bash
git commit -m "feat: adicionar suporte a group messages"
git commit -m "fix: corrigir timeout na conexao WhatsApp"
git commit -m "docs: atualizar README com exemplos Python"
```

### Codigo

- Mantenha o codigo limpo e legivel
- Adicione comentarios quando necessario
- Teste suas mudancas antes de enviar
- Siga o estilo existente do projeto

## Duvidas?

Abra um issue com a tag `question`.
