# WhatsApp API - Nexus Dashboard

API completa do WhatsApp com dashboard futurista, multi-sessao, envio de mensagens (texto, imagem, video, audio, localizacao, enquete) e lista de contatos.

## Funcionalidades

- Multi-sessao com QR Code
- Envio de mensagens (6 tipos)
- Lista de contatos
- Dashboard futurista com design neon
- Socket.IO para atualizacoes em tempo real
- Auto-reconexao

## Como Usar

```bash
npm install
node server.js
# Acesse http://localhost:3000
```

## Stack

- Node.js + Express
- whatsapp-web.js (Chrome/Puppeteer)
- Socket.IO
- Design futurista com glassmorphism
